# Telegram Exporter

Программа с окном для выгрузки чатов Telegram — замена встроенному экспорту Telegram Desktop,
который может надолго встать на одном файле до нажатия «Skip this file».

Результат в том же формате, что у Telegram Desktop («Both»): страницы `messages.html`, `messages2.html`, …
и `result.json`, файлы разложены по папкам `photos`, `video_files`, `voice_messages` и т. д.

## Возможности

- **Не зависает на файлах.** Файл пропускается, только если по нему совсем не приходят данные
  (по умолчанию 120 с); большие файлы спокойно качаются сколько нужно. Пропущенные — в `failed.txt` и отчёте.
- **Продолжение после любого сбоя.** Недокачанный файл докачивается с места обрыва, сканирование истории
  продолжается с последней контрольной точки (каждые 15 с). Обрыв связи — программа ждёт её и продолжает сама.
- **Экспорт всех чатов** одной кнопкой: личные, группы, каналы; ошибка в одном чате не останавливает остальные.
- **«Мои экспорты»** — как в торрент-клиентах: список чатов с состоянием, прогрессом, скоростью и прогнозом,
  график скорости (наведите курсор — покажет скорость в этой точке), журнал; продолжить, начать заново, открыть результат.
  После обрыва прогресс считается по всему чату, а не заново с 0%.
- **Версии сканирования**: после каждого сканирования сохраняется снимок истории — из любой версии можно
  собрать экспорт (сохраняются сообщения, удалённые позже).
- **Прогноз окончания** сканирования с учётом пауз, которые делает Telegram, и скачивания.
- Многопоточная загрузка, проверка свободного места, лимит размера файла, выбор типов медиа.
- **Вход по QR-коду** (или по номеру), облачный пароль.
- **Прокси**: MTProto (в т. ч. [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy)), SOCKS5 или без прокси.
- Режим экспорта Telegram (takeout) — меньше пауз при чтении истории.
- **Проверка связи** по шагам: сначала VPN, потом (после выключения VPN) прокси MTProto / SOCKS5 — пинг, скорость скачивания и подсказка, где быстрее.
- Список чатов с галочками, сортировкой и числом сообщений; экспорт выбранных чатов по очереди или «сначала сканировать все».
- Нехватка места: скачивание встаёт на паузу и продолжается само, когда место освободили.
- Копирование и вставка (Ctrl+C / Ctrl+V / Ctrl+X / Ctrl+A и правая кнопка мыши) в любой раскладке.
- Русский и английский интерфейс (по умолчанию — язык системы).
- Светлая и тёмная тема, чёткое отображение при масштабе Windows 125–200%.

## Запуск (Windows)

1. Установите Python 3.11+ с [python.org](https://www.python.org/downloads/), отметив «Add python.exe to PATH».
2. Дважды щёлкните **`Запуск.bat`** — при первом запуске он сам установит нужные пакеты.
3. На странице «Подключение» укажите API ID и API hash
   (их бесплатно выдают на [my.telegram.org](https://my.telegram.org/apps) → API development tools)
   и нажмите «Подключиться».

Вручную:

```
pip install -r requirements.txt
python tg_export_gui.py
```

## Файлы

| Файл | Что это |
|---|---|
| `tg_export_gui.py` | программа с окном (основная) |
| `Запуск.bat` | запуск в Windows с установкой пакетов |
| `app_icon.ico` | иконка программы |

Настройки сохраняются в `tg_export_settings.json`, вход в аккаунт — в `tg_export_session.session`
рядом с программой. **Никому не передавайте эти файлы**: по ним можно войти в ваш Telegram.
Оба файла исключены из репозитория (`.gitignore`).
